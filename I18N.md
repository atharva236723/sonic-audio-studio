# Languages and multilingual SEO

The existing static MPA follows the directory-routing, dictionary and language-switching approach in the [Astro i18n recipe](https://docs.astro.build/en/recipes/i18n/). This integration does not migrate the audio editor to Astro or add a server requirement.

English remains at `/`. Spanish, Japanese, French, German, Portuguese, Korean and Italian use `/es/`, `/ja/`, `/fr/`, `/de/`, `/pt/`, `/ko/` and `/it/`. Each locale has all 24 pages, including the 17 effect studios, home, combination studio, chooser and four information pages. Translated guides are localized adaptations of the English content, not automatic browser translations. Brand names, formats and frequency units are preserved.

Every HTML document contains its actual language content before JavaScript runs, `<html lang>`, a self-referencing canonical, localized title/description/Open Graph/Twitter metadata, and nine reciprocal alternate links: en, es, ja, fr, de, pt, ko, it and x-default. The default targets the equivalent English page. All 192 canonical pages are in sitemap.xml. Each localized home has visible FAQs with matching localized FAQ JSON-LD. FAQ markup does not promise Google FAQ rich results.

The language menu links to the equivalent page and preserves query parameters and anchors. No IP/browser-language forced redirects or third-party translation requests are used. A language change is an MPA navigation; if audio is loaded, a warning advises downloading the result first because navigation clears the in-memory session.

## Maintaining translations

Edit the root English HTML files in `dist/`, shared editor scripts, and the catalogs in `i18n/`:

- `ui.cjs`: shared interface, accessibility and live status strings.
- `effects.cjs`: effect names, explanations and control labels.
- `home.cjs`: home guide and 16 FAQs per language.
- `documents.cjs`: About, Contact, Privacy and Terms content.
- `extra.cjs`: guide labels, metadata vocabulary and runtime message templates.

Run `node build-i18n.cjs` from this folder after changes. The build regenerates localized HTML and locale JS bundles, adds English alternate links/menu idempotently, and regenerates sitemap/robots. Do not directly edit generated locale folders. New English UI strings must be added to the catalogs; untranslated unknown runtime messages fall back to their original wording. Preset labels are localized but their underlying values stay stable for DSP lookup. Audio processing algorithms and numeric defaults are unchanged.

Run `node preview.cjs` for the local preview. It supports locale directory index pages and redirects a bare locale path to its trailing-slash URL.

## Production origin

The default canonical origin is the previously registered `https://sonic-audio-studio.atharva23.chatgpt.site`. This site has not been published. For another final domain set `SONIC_SITE_URL` before running the build, then deploy the generated `dist/` directory. Canonicals, alternate links, schema URLs, sitemap and robots must all use the deployed origin. Localhost pages cannot appear in public search; language markup helps identify translated pages but does not guarantee rankings.
